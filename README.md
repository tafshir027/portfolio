
# Personal Portfolio Website – Md Tafsir Kabir Khan

A modern, responsive personal portfolio website showcasing my professional profile, data analytics skills, projects, educational resources, and contact information.

## 🚀 About The Project

This portfolio website is designed to present my expertise in Data Analysis, Business Intelligence, and Data Visualization.

It provides an overview of my professional experience, technical skills, featured projects, published books, and ways to connect with me.

## ✨ Features

- **Modern Homepage:** Professional introduction with a hero section and statistics.
- **About Me:** Personal profile, professional experience, and educational background.
- **Technical Skills:** Showcase of data analytics and visualization skills.
- **Projects Portfolio:** Categorized projects with filtering options.
- **Books & Resources:** Collection of educational books and learning materials.
- **Contact Section:** Contact information and message submission form.
- **Social Media Integration:** Direct links to professional social profiles.
- **Responsive Navigation:** Mobile-friendly navigation with a hamburger menu.
- **Interactive UI:** Animated elements, tab navigation, and interactive components.
- **Back to Top:** Quick navigation to the homepage.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome 6.4.0
